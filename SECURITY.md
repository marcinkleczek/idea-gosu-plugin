# Security policy

## Supported versions

Only the latest release on the GitHub Releases page receives fixes. Older ZIPs are not patched.

## What the plugin executes

The plugin runs code in two situations, both started explicitly by the user:

- **Run / Test actions** execute the saved script or test class with the configured Gosu SDK and JDK. The code can do whatever the script requests.
- **Check compilation in the editor** starts a separate, bounded worker process that only parses and type-checks the current document. It does not evaluate the program or run generated bytecode.

Everything else, including completion, navigation, inspections, and the explanations attached to compiler messages, is a static analysis inside the IDE process. The plugin does not contact any network service.

## Reporting a vulnerability

If you find a way to make the plugin execute code without an explicit Run, Test, or compile-check action, or to escape the limits of the compiler worker, please report it privately rather than in a public issue.

Use GitHub's **Report a vulnerability** form on the repository's Security tab if it is enabled. Otherwise, contact the repository owner through GitHub and mention that the report is security-related.

Include the plugin version, the IDE build, the operating system, and a minimal Gosu example or project layout that reproduces the problem. You should receive an acknowledgement within a week. Please allow time for a fix before disclosing the issue publicly.
